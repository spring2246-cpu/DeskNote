# 桌面随记 v0.6

Windows 自用的轻量备忘与个人财务程序。透明备忘面板常驻桌面，财务独立打开、默认锁定；无需服务器或账号。

## 下载与使用

完整操作说明见 [使用说明](使用说明.md)。Windows 便携版：[下载 DeskNote v0.6](downloads/DeskNote-v0.6-Windows.zip?raw=true)。下载后解压运行 `DeskNote.exe`。

仓库包含源码、资源及 downloads 下的便携包；从源码构建后才会出现下述 dist-v0.6 目录。

## 开始使用

双击 `dist-v0.6\DeskNote.exe`。便携压缩包解压后，双击其中的 `DeskNote.exe`；`DeskNote.exe.config` 与程序放在一起。适用于装有 .NET Framework 4.8 的 Windows 10 / 11，本项目开发环境已验证可运行。

从旧版升级时，先保存正在编辑的内容，再从旧版托盘选择“退出（停止提醒）”，然后运行新版。同一 Windows 用户下自动读取原有加密数据；不会清空原来的待办、便签和账目。`dist` 中保留旧版，`dist-v0.6` 是本次新版，两个版本不能同时运行。

1. 在面板下方添加待办或便签。拖动标题移动，右下角调整大小。
2. 点右上角“后台选项 → 个人财务”，首次设置至少8位的财务解锁口令。
3. “流水”中记录收入、支出或转账。分类和账户可直接输入自定义名称。
4. “账单”中添加一次性、月度或年度账单，指定到期时间和提前提醒天数。
5. 默认 `Ctrl + Alt + H` 隐藏所有窗口并锁定财务，可在设置中更换。
6. 隐藏后从系统托盘恢复面板。右键托盘可打开财务、备份、暂停提醒或退出。

顶部“↓”和关闭面板仅隐藏；关闭财务窗口会锁定。只有托盘“退出（停止提醒）”才结束程序。系统托盘图标可能位于任务栏折叠菜单内。

## 截图布局、透明度与桌面嵌入

新版主面板采用截图中的深蓝背景、青色强调和圆角卡片：

- 实时时钟含秒，今日时间流逝进度按实际时间计算；周数按 ISO 周规则计算。
- 本周七天视图，箭头切换前后周，“今天”返回当前周；点击日期定位相应日卡片。
- 待办按日期分组，可筛选全部、未办、已完成和高优先级；无日期事项放在“待安排”，早于当前周的未办事项另列。
- 新增和编辑待办时可设高优先级；重复待办会保留该优先级。
- “便签”筛选与底部“＋便签”保留随手记入口。
- “专注番茄”提供25分钟开始、暂停、继续和重置，结束发出系统通知。计时随程序退出结束，不跨重启保留。
- 天气默认未启用。点击天气区选择城市后，每15分钟从 [Open-Meteo](https://open-meteo.com/en/docs) 更新，可手动刷新；只发送选定城市的坐标，不自动定位。网络失败显示离线，缺失天气数据不显示伪造温度。天气温度的观测时间与系统时钟可能不同，更新时间见提示。

进入“后台选项 → 外观 / 透明度 / 桌面嵌入”：

| 选项 | 作用 |
| --- | --- |
| 背景不透明度 10%—100% | 改变面板和卡片底色，文字保持原有清晰度 |
| 整体不透明度 35%—100% | 连同文字一起改变整个窗口的不透明度 |
| 普通窗口 | 常规桌面小窗 |
| 始终置顶 | 放在普通应用上方 |
| 嵌入桌面 | 挂载到 Explorer 的桌面宿主，处于普通应用下方 |

个性化设置采用深色分类面板，包含主题配色、透明与质感、桌面壁纸、时间与时钟、本地天气、提醒与音效及 Windows 便捷选项。提供六套主题、强调色与背景取色器，配色同步桌面挂件。所有调整即时生效并自动保存，关闭时保留修改；“恢复默认”只恢复外观，不更改财务和安全设置。壁纸和系统时间分类可打开 Windows 对应设置；当前不提供毛玻璃模糊。顶部“▣”快捷切换桌面嵌入，布局锁按钮控制拖动和缩放。拖动标题移动，右下角调整大小；托盘“恢复为普通窗口”可随时解除嵌入。

桌面模式单独创建支持透明子窗口的 HwndSource，并将面板内容移入桌面宿主；切回时销毁子宿主、归还内容，普通 WPF 窗口的类型与父级始终不变。普通模式显示任务栏入口，再次打开程序会找回窗口。已通过连续12次往返切换及移动、缩放、隐藏恢复测试；实际屏幕显示须结合现场确认，Win+D、Explorer 重启、多屏混合 DPI 仍需观察。技术分析与验证边界见《桌面显示故障分析.md》。

## 当前功能

- 待办与纯文本便签：新增、编辑、删除、完成/归档、恢复、重复待办和到期提醒。
- 面板：移动缩放、透明度、可选置顶、记住位置，一键隐藏；财务提醒也可完全不显示在桌面。
- 财务：收入、支出、转账、可编辑分类/账户、月度概览、流水编辑、筛选、核对、作废恢复及 CSV 导出。
- 账单：独立期次、短月和闰年处理、提前提醒、每日去重、稍后提醒、周期规则启停。
- 支付：生成流水、关联同类型同金额的已有流水，或仅标记支付；已支付未记账的期次可补记。
- 隐私：默认锁定、空闲自动锁定、Windows锁屏/睡眠锁定，可选切换到其他应用时锁定；通知不显示名称、金额和账户。
- 数据：加密本地保存、原子替换、前一版副本、最近14天每日快照、独立口令的加密备份与恢复。
- 可选开机启动：在设置中勾选，通过当前用户的 Windows 启动项生效。

## 财务与账单规则

金额最多两位小数，采用 `decimal` 计算。可在账户页设置期初余额及起算日期；未设置时明确标为未知，不把流水净额当作完整资产。转账不计入收支；已记录消费的信用卡还款应选择转账。

每月31日遇短月使用最后一天，下月恢复31日。2月29日的年度账单遇平年使用2月最后一天。系统只生成近期所需期次以及从规则起始日期至今的漏期，已支付历史保留。

账单在提前日期的指定时刻开始提醒，之后未付默认每天至多提醒一次。显式“稍后提醒”允许当天再次提醒；托盘暂停提醒优先于账单提醒。电脑关机、睡眠、程序退出时无法实时提醒，运行和唤醒后检查补发。Windows 通知关闭或勿扰可能阻止弹出，应用内待办和账单仍保留。

账单“已支付”和“已记账”分开。编辑关联流水会同步更新该期账单的金额、类型和账户；后续规则不变。作废关联流水会解除有效记账关联，账单仍为已付，可补记；已有替代流水时不能恢复旧流水造成重复。关联已有流水时只匹配类型和金额，需自行核对日期、账户及备注。

已生成账单保留原来的金额、名称和日期。规则有已生成期次后，起始日期和周期不可直接修改；更换近期账单时，先停用旧规则、删除不再需要的未付期次，再创建新规则。重新启用旧规则会重新生成缺失期次。

重复待办按规则在对应日期独立生成，不依赖前一次完成；每天分别显示、完成和提醒。常用近期事项自动备好，浏览其他周时按需补充。编辑时可选择“仅本次”或“本次及以后”；删除本次不会在刷新后重现，也可停止本次及以后的重复。月末与闰年按最初日期计算，保留已完成记录。旧版重复事项自动迁移。重复频率下可设置“重复截止”，选择不限期，或通过年月日、小时和分钟指定截止时刻；截止分钟包含在内，之后停止新事项生成及重复提醒。缩短截止范围会清理超出范围的未完成期次，保留已完成及归档记录。新增待办默认当前小时和分钟；从某日添加时保留选中日期，年、月、日、小时和分钟均通过下拉选择，00分表示整点。

## 数据安全与恢复

实际数据存放于 `%LOCALAPPDATA%\DeskNote`，不在程序目录中：

| 文件 | 用途 |
| --- | --- |
| `desk.dat` | 当前加密数据 |
| `desk.dat.previous` | 上一次保存前的加密副本 |
| `auto-yyyyMMdd.dat` | 最近14天每日最新快照 |
| `before-restore-*.dat` | 每次恢复前保留的数据，不自动清理 |

所有本地数据（包括便签）使用 Windows DPAPI 当前用户加密。解锁口令采用随机盐与 PBKDF2 验证，是应用内访问门禁；本地文件的加密身份属于当前 Windows 用户，不能抵抗同账户下的恶意程序或阻止截图。程序不保存银行密码、不连接支付平台。

**迁移或重装系统前，使用“加密备份”导出 `.dsnb` 文件。** 它使用独立备份口令、PBKDF2、AES-CBC 与 HMAC-SHA256，先验证完整性再解密，可在其他电脑恢复。本机 `.dat` 快照依赖原 Windows 用户密钥，不可作为跨电脑迁移文件。

恢复 `.dsnb` 只需备份口令，之后设置新的解锁口令；即使忘记原解锁口令也可恢复。备份口令无法找回；没有可用备份时不能通过本程序绕过解锁口令。恢复会替换全部待办和财务数据，并先保存恢复前快照；本机面板位置与应用设置保留。

本机 `.dat` 快照恢复后沿用快照中的解锁口令；原解锁口令已忘记时应使用 `.dsnb` 恢复。若主文件损坏，启动时提供恢复入口，不会静默覆盖损坏文件。选择文件时可切换到“所有文件”读取 `desk.dat.previous`。

CSV导出包含明文财务信息，程序会在导出前明确提示。自动备份仅在程序成功保存数据时更新；备份写入失败不阻止主文件保存，因此重要数据请定期独立导出备份。

## 构建与验证

源代码在 `src`，无需 NuGet 依赖。PowerShell 在项目目录运行：

```powershell
.\build.ps1
```

使用本机 Windows 用户环境执行测试，测试文件写入 `test-output`，与真实数据隔离：

```powershell
.\test.ps1
# 可选：城市级在线天气连通性检查
Start-Process .\dist-v0.6\DeskNote.exe -ArgumentList '--weather-test','test-output' -Wait
```

- `self-test.txt`：日期、支付一致性、加密、备份、保存失败回滚等逻辑检查。
- `render-test.txt`：通过实际 WPF 编辑窗口新增数据、支付与编辑关联流水、隐私检查；同时生成预览图。
- `smoke-test.txt`：正式启动路径、托盘、调度、暂停、自动锁定与损坏文件恢复检查，会显示一条测试提醒。
- `desktop-test.txt`：真实桌面挂载、透明度、移动缩放、隐藏恢复、解除挂载及设置持久化检查。
- `weather-test.txt`：一次上海城市级在线天气连通性与解析检查。联网失败时记录不可用状态。

本版使用加密文件而非方案中建议的 SQLite，适合单人少量数据；没有数据库服务，备忘、财务和提醒均可离线使用，天气需要联网。暂未实现贴边隐藏、手机同步、多币种折算及投资管理。系统锁屏事件与全局快捷键已有实现；实际硬件睡眠、系统勿扰、多屏混合DPI和长期后台运行仍需使用中验证。











## v0.6 新功能

- “找回面板”：托盘、后台选项及 Windows 设置页共用恢复入口，解除嵌入、移回可用主屏并保存正常透明度。显示器变化时检查标题是否仍能触达；原生桌面渲染窗口丢失后重建，保留最近位置。后台可导出不含正文或财务明细的显示诊断。
- “个人财务 → 账户”：账户改名保留历史归属；设置期初余额和起算日期，可为负数。起算日余额是当天流水发生前的余额，早于起算日的历史不再重复计算。期初余额留空表示未核实，不显示伪造总资产。停用保留账户与历史。
- 转账分别影响转出和转入账户，收入、支出统计及总资产净变化不增加。账户页显示截至今天的余额。
- “流水”：按账户、月份、分类、状态及关键词筛选，CSV 与筛选结果一致并包含状态。核对、取消核对、作废和恢复均保留记录；修改已核对流水前提示，保存后回到待核对。编辑前后详情及操作记录跟随账本加密保存。
- 作废关联流水后，账单保留支付事实，可补记有效流水；存在替代流水时，阻止恢复旧流水造成重复入账。作废流水须恢复后再编辑。
- “后台选项 → 搜索与归档”：搜索待办、便签、已完成和归档内容；支持编辑、归档本条、恢复本条及定位。归档事项不提醒、不在桌面显示；后续系列仍独立生成。停止或修改系列时保留已归档历史；恢复归档不重新启用已停止的系列。
- “预算与预测”：每月分类预算显示实际已用、剩余或超出；再次设置同分类可修改预算。30/90/365 天预测分开计算未来已录流水和未付计划（含逾期），按启用规则推演周期，不自动记账、不重复计算支付，不预测未录入消费。

旧账户名称首次升级时自动转为固定身份，并在数据目录保留 `before-accounts-日期.dat` 加密快照。名称按原文精确匹配，不猜测不同名称是否为同一账户。先核实各账户期初余额与日期后再使用总余额；暂不提供多币种折算。预算和预测默认按同一记账币种计算。

保留 Windows 用户加密、独立备份口令、财务锁定、桌面脱敏及重复待办截止机制。显示器混合缩放、真实 Explorer 进程重启与 Win+D 仍需在实际设备验证；自动测试覆盖了独立渲染窗口被销毁后重建及反复切换，不能代替全部硬件场景。
